# 吃什么 · WhatToEat

今晚吃什么：设好需求 → 看推荐 → 点一道菜，看怎么做（买菜 / 备菜 / 切菜 / 烹饪 / 关键一步），
不想做就按上面给的备注去点外卖。

纯单机，不要账号，不联网。

## 现在能跑什么

直接双击 `index.html` 就能用（数据是 js 文件，`file://` 也能跑）。
想用手机试，在 `dinner-app` 里起个静态服务器，手机同网段访问：

```bash
python -m http.server 8080     # 或者 npx serve .
```

出安卓包看 [DELIVERY.md](./DELIVERY.md)。

## 数据从哪来

做法全部来自 [Anduin2017/HowToCook](https://github.com/Anduin2017/HowToCook)，
**Unlicense（公有领域）**，可以随 App 分发。它的 markdown 是固定四段：

| 菜谱里的段落 | 存成 | 详情页显示成 |
|---|---|---|
| 必备原料和工具 | `ing[]` / `tools[]` | 买菜 |
| 计算 | `calc` | 买菜下面的份量说明 |
| 操作 | `prep[]` / `cut[]` / `cook[]` | 备菜 / 切菜 / 烹饪 |
| 附加内容 | `extra` | 关键一步 |

「备菜 / 切菜」不是源数据里的独立字段，是从「操作」按动词拆出来的（切/剁 → 切菜；
腌/焯/打散 → 备菜；剩下的进烹饪）。拆不准的句子会留在烹饪里，不会丢。

HowToCook 的头部还有 `预估烹饪难度：★` 和 `预估卡路里：191 大卡`，这两个能直接用：
`diff` 存 1/2/3，`kcal` 存整数。

**没有**的是「烹饪时长」和「风味/口感 0–5 分」。这两项留空，App 对缺失值是中性处理：
没有风味标注就不生成「第一口辣、回口脆」这种话，换成「步骤写得细，照着做就行」「来自公开菜谱库，不是编的」；
没有时长就不显示分钟数，排序时用步骤条数当省事程度的替身（只参与排序，不当时间显示）。

`data/dishes.js` 里那 16 道是手工标的（含 5 道外卖专属），用来验证交互和排序；
真实数据用转换脚本生成（已跑过，374 道全量在 `data/dishes.generated.js`）：

```bash
git clone --depth 1 https://github.com/Anduin2017/HowToCook.git
node tools/howtocook2json.mjs --src ../HowToCook --out data/dishes.generated.js --json data/dishes.generated.json
```

`index.html` 会自动优先用 `data/dishes.generated.js`（存在时），没有就回落到演示数据，不用手改。

真实数据实测：374 道，缺原料 1 道、缺操作 0 道、缺热量 0 道。
2026 年版的仓库格式和旧文档写的不一样（`dishes/<分类>/<菜名>.md` 平铺、操作用 1. 2. 3. 有序列表、
计算段是「1 颗 油麦菜（约 200g） * 份数」量在前面），脚本两种布局都支持。

### 麻辣烫这类没有菜谱的

HowToCook 全库没有麻辣烫（`semi-finished` 里只有 10 条：凉皮、速冻水饺、牛油火锅底料……）。
所以外卖专属菜显示「这道菜开源菜谱库里没有现成做法，先不瞎编」，下面给一条通用思路，不编步骤。

### 「看视频」

没有任何可以离线分发的小红书视频数据集，所以是按菜名拼搜索链接：
`https://www.xiaohongshu.com/search_result?keyword=<菜名> 做法`。点了会跳浏览器。

## 排序怎么算

`score = 健康 0.42 + 感官 0.30 + 冰箱命中 0.16 + 时间 0.12`
（外加一点点按 seed 变化的扰动，「换一批」就是换 seed）

- 健康：按目标（减脂/增肌/控糖/低钠/养胃）对 kcal、糖、盐、辣、tag 加减分；
  没设目标时用「热量离 550 kcal 这顿晚饭合理区间有多远」当默认维度。
  否则 374 道菜会全部同分，排序退化成随机。
- 感官：把「想吃的味道」「口感偏好」映射到菜品 0–5 分的坐标轴上取均值
- 冰箱：已选食材在菜品原料里的命中率
- 时间：有真实时长就用时长，没有就用步骤条数估算省事程度；都没设时按 30 分钟兜底
- 一次三张卡不会全是同一类（先每类一个，不够再回填）

## 已知没做的

- 真实外卖下单：不做，只给「搜什么、备注怎么写」
- 烹饪时长 / 风味口感的自动标注：需要另跑一轮标注（脚本不猜）。这也是排序目前最弱的一环——
  374 道菜里只有热量是真实数据
- 菜品图片：现在是按分类的 emoji，接真图要另找可分发授权的图源
