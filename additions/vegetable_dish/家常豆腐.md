# 家常豆腐的做法

豆腐片煎黄，配五花肉和青椒木耳一起烧，汤汁浓稠裹在豆腐上。

预估烹饪难度：★★

预估卡路里：300 大卡

## 必备原料和工具

- 老豆腐 400g
- 五花肉 100g
- 青椒 1 个
- 木耳 15g
- 蒜 3 瓣
- 豆瓣酱 15g
- 生抽 15ml
- 白糖 3g
- 淀粉 5g
- 食用油 30ml

## 计算

每次制作前需要确定计划做几份。一份正好够 2 个人吃。

每份：

- 老豆腐 400g
- 五花肉 100g
- 青椒 1 个
- 木耳 15g（干重）
- 蒜 3 瓣
- 豆瓣酱 15g
- 生抽 15ml
- 白糖 3g
- 淀粉 5g
- 食用油 30ml

## 操作

1. 豆腐切三角片，煎至两面金黄盛出。
2. 木耳泡发撕小朵，青椒切块，五花肉切薄片。
3. 锅下五花肉煸出油，加蒜末和豆瓣酱炒出红油。
4. 下木耳和青椒炒 1 分钟。
5. 倒回豆腐，加生抽、白糖和 150ml 水，小火焖 3 分钟。
6. 淀粉勾芡，收汁出锅。

## 附加内容

- 豆瓣酱本身很咸，盐可以不放。
